# 墨粒 · 自由画猜

倪悦雅 · 202421114060

一个使用真实 QuickDraw 数据训练模型的自由涂鸦识别基础版。鼠标、触控笔和手指都可以绘画。当前提供 12 类实时识别、前三名预测、用户确认、撤销、清空、PNG 导出和演示署名。作品粒子化及标准图案变形留在后续版本。

## 启动

本机可双击 `启动项目.command`，然后在浏览器打开 http://127.0.0.1:8765 。如果系统不允许双击脚本，可在终端进入本文件夹后执行 `zsh 启动项目.command`。

换一台电脑时：

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 server.py
```

模型已包含在项目中，日常运行无需重新下载数据或训练。不要直接双击 HTML 文件，浏览器需要通过 HTTP 加载模型和模块。

## 前端、后端和模型训练分别在哪里

| 部分 | 文件 | 职责 |
| --- | --- | --- |
| 前端页面 | `dist/index.html`、`dist/styles.css` | 画板布局、预测展示、个人署名 |
| 前端交互 | `dist/app.js` | 记录笔画，每 500 毫秒按需预测，撤销、清空、确认和保存 |
| Python 后端 | `server.py` | 托管前端，校验输入，调用模型，返回预测结果 |
| 数据预处理 | `ml/features.py` | 笔画居中与缩放，栅格化成 28 × 28 灰度图 |
| 离线训练 | `ml/download.py`、`ml/train.py` | 下载真实数据、划分数据集、训练、评估、导出模型 |
| 浏览器备用推理 | `dist/predict-worker.js`、`dist/model.js`、`dist/features.js` | 静态部署时在 Web Worker 中运行相同权重 |
| 训练结果 | `dist/assets/metrics.json` | 数据数量、训练历史、准确率、混淆矩阵与限制 |
| 误判案例 | `dist/assets/failures.json` | 每类最多两个真实测试集误判，包含笔画与预测 |

**本地课程演示的调用过程：** 前端采集笔画，向 `/api/predict` 发送 JSON。后端统一预处理，计算 MLP 输出，返回 12 类分数。前端按分数显示前三名。姓名和学号不会发送给模型。

**独立网页演示：** 没有 Python 后端时，前端在 Web Worker 中加载同一份权重。它仍是真实模型推理，且不阻塞画板主线程。源码中的 Python 与 JavaScript 预处理、预测结果有一致性测试。

两种方式都不调用收费大模型接口、不把绘画发给第三方服务，也没有把输入答案写入预测逻辑。页面中的“测试集示例”有明确标识，示例的预测也由同一个模型实际计算。

## 支持范围和真实结果

支持苹果、香蕉、自行车、鱼、花、房子、冰淇淋、月亮、星星、太阳、树、雨伞。可以自由绘画，但识别模型只在这 12 类之间分类，并不保证检测出其他物体。

本次训练使用官方 simplified 笔画格式，每类前 2400 条 `recognized=true` 样本。使用固定随机种子 42 打乱，各类别按 80% / 10% / 10% 划分。先按原始画作划分，再给训练集添加部分笔画样本。

- 原始训练图：23,040 张。
- 加入部分笔画后：28,800 个训练样本。
- 验证集：2,880 张，只用于选择训练轮次。
- 测试集：2,880 张，选择好模型后评估。
- 模型：784 → 128 → 64 → 12 的多层感知机，ReLU 隐藏层，Softmax 输出，Adam 优化。
- 本次独立测试集首选命中率：86.32%。前三名命中率：97.01%。

这些是完整数据集画作的结果，不是用户实际随手绘画的保证。初始数据经过 `recognized` 筛选，且每类只截取有限数量，存在选择偏差。未完成的笔画、陌生类别、不同画风可能导致错误。页面百分比是未校准的分类分数，高分仍然可能错误。用户点击候选的勾才表示确认猜中。

基础版采用 MLP 以减少安装依赖并便于解释。后续可以在保留输入与接口的情况下换成 CNN。当前保留轨迹并对部分轨迹增强，但没有直接学习笔画时间序列，不能在报告中声称是 RNN 或轨迹序列模型。

## 重新训练

```sh
python3 ml/download.py --per-class 2400
python3 ml/train.py --epochs 28
```

原始数据保存在 `ml/data/`，不提交到源码仓库。首次训练会生成本地特征缓存；数据文件或随机种子变化会使缓存失效。修改预处理实现后，应增加 `preprocessing_version` 或移走缓存文件，再重新训练。

## 检查

```sh
node --test tests/model.test.mjs
# 先启动 server.py，再运行：
python3 tests/test_api.py
```

模型测试覆盖 Python/JavaScript 图像与预测一致性、平移缩放一致性、空输入、数据集隔离。API 测试覆盖真实预测、空画、无效输入和不存在的接口。

## 演示建议

1. 展示页面顶部的个人署名，自己画一幅支持类别中的涂鸦，观察预测变化。
2. 继续补画，确认任意一个正确候选，再撤销或清空，展示系统真实更新。
3. 演示空白或点状输入，以及一张模型猜错的画，解释识别范围和不确定性。
4. 打开 `server.py` 的预测接口、`ml/features.py` 的预处理、`ml/train.py` 的训练流程，按实际理解讲解。
